# InHaus Digital website

Copy and code for https://www.inhausdigital.com.au, a Squarespace 7.1 site.

Squarespace 7.1 has no way to sync page content with a code repository, so this repo holds:

- **`copy/`**: page text, written section by section to paste into the Squarespace editor.
- Custom CSS and code snippets for design changes (to come).

## Page copy

Replaces the template text still on these pages:

- [Contact](copy/contact.md)
- [Bottom links and Subscribe section](copy/bottom-section.md) (on all three pages)

Anything in [square brackets] needs filling in or confirming before it goes live.

## Other fixes spotted on the site

- **Duplicate homepage at `/page`.** It's in the sitemap, so search engines can find it. Delete it from the Pages panel.
- **Homepage typos:** "Give us the reigns" → "reins"; "ABandonment" → "Abandonment"; "Segementation" → "Segmentation"; "Optimmisation" → "Optimisation".
- **Homepage numbers don't match.** "Meet the dynamic duo" says Style My Wall is *on track* for $8–10M in year two, while "Why Us?" says you *scaled it* to $8–10M. The new About page copy uses "on track"; update it if the other wording is right.
- **No site description for search results.** Add one in **Marketing → SEO**.
